# 🧠 Prathamesh's AI Voice Assistant-"Neox"

A JARVIS-inspired intelligent voice assistant built in Python. It can recognize your speech, respond using a natural voice, perform tasks like opening websites, playing music on YouTube, checking weather, fetching Wikipedia summaries, and even taking a picture using your webcam.

---

## 🎯 Features

- 🎤 Voice recognition using your microphone
- 🗣️ Text-to-Speech responses
- 📺 Play music on YouTube
- 🌤️ Check real-time weather
- ⌚ Tell the current time
- 📚 Fetch short summaries from Wikipedia
- 🌐 Open common websites like Google, YouTube, LinkedIn, etc.
- 💻 Shutdown or restart your computer
- 📸 Take a picture using your webcam
- 🔊 Control volume through voice
- 👋 Personalized greeting based on your name and current time

---

## 🛠️ Tech Stack

- Python 3
- [SpeechRecognition](https://pypi.org/project/SpeechRecognition/)
- [pyttsx3](https://pypi.org/project/pyttsx3/)
- [Google API Client](https://pypi.org/project/google-api-python-client/)
- [OpenWeatherMap API](https://openweathermap.org/api)
- [Wikipedia API](https://pypi.org/project/wikipedia/)
- [OpenCV](https://pypi.org/project/opencv-python/)
- [pycaw](https://github.com/AndreMiras/pycaw)
